# Saad & Frankie: Outreach and Conversation Casebook

**Purpose:** reconstruct what Saad actually did in real prospect conversations:

- what he knew before sending;
- what he wrote;
- what came back;
- why he made each next move;
- how each conversation ended.

The casebook sits alongside Frankie's methods and the sales documents the user supplied. It's the evidence base for the next design documents: the opportunity brief, the outreach standard and the reply framework. **Research only; it doesn't change any skill.**

## How to read it

| File | What it is |
|---|---|
| `01-source-inventory.md` | All 61 Saad transcripts: which contain real prospect threads, how complete, exact or summarized, the outcome shown, and which case file covers them |
| `cases/A01–A13` | **Threads ending in payment** (12 closed by email, A13 by call) |
| `cases/A14–A20` | **Unresolved threads** that show objections, reply handling, matching and calls |
| `cases/A21-other-threads.md` | Shorter threads: staffing, rural lending, agency-era campaigns, the S23 role-play |
| `part-b-sales-documents.md` | Teardowns of the 11 Google Docs (Frankie, Forever Booked, Dan Wardrop, James Kemp): text and images |
| `part-c-findings.md` | **The synthesis:** outcomes, when he skips calls, the decision patterns (moment → move), kinds of replies, first-email structure, the honesty audit, market signals, Frankie alongside Saad, and implications for the design documents |

**Start with `part-c-findings.md`,** then read the cases it cites.

## Each case file contains

1. **Header:** source, era, who paid, outcome, wording status.
2. **What he knew before sending:** the trigger, data, price logic and honesty level.
3. **The outreach:** the exact emails to each side, with what each question tests.
4. **Conversation timeline:** each reply quoted, and what it revealed.
5. **The close, warm-up and intro:** exact.
6. **Decision analysis:** what he did, why (his words, or *inference* where marked), and what he chose not to do.
7. **Frankie comparison.**
8. **Rules:** transferable, specific to the market, **do not copy**.

## Labels used

| Label | Meaning |
|---|---|
| **Exact** | Read on screen from the real emails. Transcripts are machine-made, so punctuation and capitals are added; the words are unchanged. `[brackets]` mark garbled, skipped or anonymized words |
| **Summarized** | Saad described it rather than reading it |
| **Inference** | My reading of why he did something, where he didn't say |
| **Outcome** | Only what the video shows. **Nothing after the introduction is shown in any case** |
| **Honesty levels** | 1 researching / 2 public signal / 3 the other side engaged / 4 confirmed opportunity. Saad's first emails usually wrote level-2 situations as level-3 claims ("I have X…"); the cases flag each one and give a truthful version |
| **Evidence ladder** (from the user's guide U1) | Signal → potential need → positive response → confirmed requirement → qualified supplier fit → commercial agreement → delivered introduction |

## Limits

- **Selection bias.** These are published videos, mostly wins. Non-replies and losses are mostly invisible, so reply and close **rates** can't be learned here.
- **Whether the introductions turned into business** is never shown.
- **Saad's income and result claims are his own** and unverified.
- **Not covered:**
  - the U1 "4,600-word field guide" (not provided);
  - resources Saad mentions but didn't share (Google Docs of copy, prompts, ConnectOS docs).
