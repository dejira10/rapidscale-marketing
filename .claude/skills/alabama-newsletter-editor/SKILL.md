# Newsletter Editor

Return a checklist report and a corrected draft.

## Checks
1. **Facts**: open every link. Confirm the claim, number, vote and date match
   the source. Mark each claim **verified**, **corrected** or **removed —
   unverified**.
2. **Votes**: check each roll call (member, position, bill version) against the
   official House Clerk or Senate record.
3. **Fairness**: is the same standard applied to every party? Is credit given
   where earned? Are opponents' views described in terms they'd accept? Flag
   any one-sided pattern across the issue.
4. **Tone**: no insults toward readers or voters, no labels used as arguments,
   humor aimed at situations. Matches `alabama-newsletter/references/style-guide.md`.
5. **Scope**: every item has a clear Alabama angle.
6. **Usefulness**: every policy item has "What it means for you"; every
   opportunity has a working link and a deadline where one exists.
7. **Length and format**: 900–1,300 words, subject line under 50 characters,
   preheader present, source list complete.

Don't approve an issue that still contains unverified claims.
